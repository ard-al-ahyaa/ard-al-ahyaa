# 🌿 منصة أرض الأحياء
تم عمله من قبل محمد حامد 
منصة تعليمية إلكترونية مخصصة لطلاب **الصف الثالث الثانوي – مادة الأحياء**.

## 📚 أقسام المنصة

- 🎥 المحاضرات
- 📖 المذكرات
- 💬 المنتدى
- 👤 حساب الطالب

## ✨ مميزات المنصة

- واجهة عربية بالكامل.
- تصميم متجاوب مع الهاتف والكمبيوتر.
- نظام تسجيل دخول وإنشاء حساب.
- لوحة تحكم للإدارة.
- رفع وتنظيم المحاضرات والمذكرات.
- إدارة المستخدمين.
- استخدام Supabase لإدارة الحسابات والبيانات.
- استضافة الموقع عبر GitHub Pages.
